# LiveFake 説明書

実況向け日本語掲示板ブラウザ LiveFake のユーザーマニュアルです。

---

## 1. はじめに

### 1.1 LiveFake とは

5ch.io / したらば / JPNKN に対応した、実況用途に特化したデスクトップ掲示板ブラウザです。
新着レスの自動取得・新着ペイン・字幕ウィンドウ・音声読み上げなど、配信や実況を見ながらの利用を想定した機能を備えています。

### 1.2 動作環境

- Windows 10 / 11 (64bit) (動作確認は Windows 11 で実施)
- WebView2 Runtime (通常はプリインストール済み)

---

## 2. インストールと起動

1. GitHub Releases から `livefake-win-x64.zip` をダウンロード
2. 好きな場所に ZIP を展開
3. `livefake.exe` を起動

インストール作業は不要です。設定・履歴などはすべて EXE と同じフォルダの `data/` に保存されます (Portable 形式)。
AppData にはファイルを作らず、レジストリにも書き込まないため、アンインストールはフォルダごと削除するだけです。

> 二重起動は防止されます。すでに起動中の場合は既存のウィンドウが前面に出ます。

---

## 3. 画面構成

- **メニューバー**: ファイル / 編集 / 表示 / 板 / スレッド / 設定 / ヘルプ
- **タブの左端の色の線**: 板タブ・スレタブの左端に、サイトごとの色 (5ch=橙 / したらば=緑 / JPNKN=青) の線が付きます (設定 > 表示 でオンオフ)
- **ツールバー**: 板一覧切替・板更新・アドレスバー・自動更新・NG
- **[板ボタンバー]**: 設定でONにするとお気に入り板ボタンを表示
- **板一覧ペイン**(左): 板一覧 / お気に入り
- **右側**:
  - 板タブバー・スレタブバー
  - スレ一覧 または レス表示、右に **[新着ペイン]**
  - **[書き込みウィンドウ]**(開閉式)
- **ステータスバー**: 状態・スレ数・未読数

(`[ ]` を付けた項目は設定でON/OFFできます)

- 各ペインの境界はドラッグでリサイズでき、次回起動時も維持されます
- 表示メニュー「レイアウトリセット」で初期配置に戻せます

## 4. 板を開く

### 4.1 板ツリー (左ペイン)

- 「板一覧を取得」(板メニューまたはツールバーの板更新ボタン) で 5ch の板一覧を取得します
- カテゴリをクリックで開閉。展開状態は記憶されます
- 上部の検索ボックスで板名を絞り込めます (検索中は自動で全カテゴリ展開)

### 4.2 お気に入り板

- 板名の右の ★ をクリックでお気に入り登録/解除
- お気に入り板は専用カテゴリに表示され、ドラッグで並べ替えできます
- 設定「板ボタンバー」を ON にすると、お気に入り板がツールバー下にボタンとして並びます (ドラッグで並べ替え可)

### 4.3 外部板の登録 (したらば / JPNKN)

1. 板一覧ペインの「外部板を追加」に板 URL と板名を入力
   - したらば例: `https://jbbs.shitaraba.net/game/12345/`
   - JPNKN 例: `https://bbs.jpnkn.com/xxxxx/`
2. 「外部板」カテゴリに追加されます。× で削除できます

### 4.4 板タブ

- 板を開くと上段の板タブに追加されます。クリックで切替
- ドラッグで並べ替え、右クリックでお気に入り追加/削除・URL コピー

### 4.5 アドレスバー

ツールバーのアドレスバーに URL を入力して「移動」(または Enter):

- スレ URL → スレタブで開く
- 板 URL → スレ一覧を取得
- `twitch.tv/チャンネル名` → Twitch タブで開く (11.6 節)
- YouTube のライブ配信の URL → YouTube タブで開く (11.9 節)

5ch / したらば / JPNKN の URL 形式を自動判別します。

## 5. スレッド一覧

### 5.1 列と並び替え

| 列 | 内容 |
|----|------|
| ! | 取得済み (キャッシュあり) マーク |
| 番号 | 一覧上の番号 |
| タイトル | スレタイトル (カスタムタイトル設定可) |
| レス | 現在のレス数 |
| 既読 | 前回取得時のレス数 |
| 新着 | 未読レス数 |
| 最終取得 | 最後に開いた時刻 |
| Since | スレ作成日 |
| 勢い | レス数÷経過日数 (バー表示付き) |

- 列見出しクリックでソート (再クリックで昇順/降順)
- 列境界のドラッグで幅変更、ダブルクリックで幅リセット
- 設定「スレ一覧の更新時にソートを維持」で更新後もソートを保てます

### 5.2 ツールバー

- **検索**: タイトル部分一致で絞り込み。Enter で検索履歴に保存 (最大20件、ドロップダウンから再利用)
- **更新**: スレ一覧を再取得
- **スレ立て**: 新スレ作成ダイアログを開く
- **dat落ちキャッシュ**: 現行一覧にないキャッシュ済みスレを表示 (dat 落ちスレの閲覧)
- **お気に入りスレのみ表示**: お気に入り登録したスレだけを表示し、新着数をまとめて確認
- **スレタイNG**: スレタイトルの NG ワードを管理 (件数バッジ付き)

### 5.3 スレを開く・既読管理

- 行クリックでスレタブで開き、既読になります
- 行ダブルクリックで栞 (前回読んだ位置) のレスへジャンプ
- 未読スレ・新着ありスレは行の色で区別されます

### 5.4 右クリックメニュー

既読にする / 未読にする / スレ URL をコピー / スレタイをコピー / タイトルを変更 (カスタムタイトル) / スレタイと URL をコピー / ブラウザで開く / スレタイ NG に追加 / お気に入りに追加・解除 / キャッシュから削除

## 6. レスを読む

### 6.1 スレタブ

- クリックで切替。**スクロール位置・選択レス・新着位置はタブごとに記憶され、戻ったときに復元されます** (最下部で離れた場合は最下部=最新レスへ)
- ダブルクリックで新着取得、**中クリックで閉じる**
- ドラッグで並べ替え。タブ上限 (既定20、設定で1〜50) に達すると新規タブは開けません
- 右クリック: タブを閉じる / 他のタブを閉じる / すべて閉じる / スレタイ・URL コピー / スレ全体をコピー / キャッシュから削除

### 6.2 スレタイトルバー

タイトル・レス数・最終取得時刻の表示と、新着取得 (▼で「キャッシュ削除して再読み込み」も選択可)・書き込み・検索・字幕・読み上げ・新着ペイン再表示・お気に入り登録の各ボタンがあります。

### 6.3 レスの見かた

```
1 [自分] 名前 [sage] (ワッチョイ) ▼3   New! 2025/01/01(水) 12:00:00 ID:abcd1234 (1/5) BE:12345
本文...
```

- **レス番号**: クリックでメニュー (引用など)
- **[自分] / [自分宛]**: 自分が書き込んだレス / 自分へのアンカーが付いたレス (自動検出)
- **▼N**: このレスへのアンカー数。ホバーで参照元レスをポップアップ表示
- **ID**: クリックでメニュー (NG追加など)、ホバーで同一 ID のレス一覧をポップアップ。書き込み回数 (n/総数) は 2回以上=青、5回以上=赤
- **BE:番号**: クリックでメニュー (プロフィール表示・スレ抽出など)

### 6.4 アンカーポップアップ

本文中の `>>N` にマウスを乗せると該当レスをポップアップ表示します。
`>>2-10` (範囲) や `>>2,5,8` (複数) にも対応し、ポップアップ内のアンカーからさらに多段表示できます。

### 6.5 画像

- 本文中の画像 URL (jpg / png / gif / webp) は自動でサムネイル表示されます
- サムネイルクリックで別ウィンドウ表示
- ホバープレビュー (設定で ON/OFF・遅延調整、または Ctrl+ホバー)。プレビュー中は Ctrl+ホイールでズーム (10〜500%)
- 右クリック「画像を保存」で保存先フォルダへダウンロード
- 画像サイズ制限 (KB) を設定すると、大きい画像は「クリックで表示」になります

### 6.6 AA (アスキーアート)

AA と思われるレスは自動で等幅フォント表示になります。誤判定は右クリック「AA表示切替」で直せます。

### 6.7 自動スクロールと新着

- 自動更新で新着レスを取得すると「ここから新着」セパレータと New! マークが付きます
- 自動スクロール ON のとき、新着取得時に最下部まで自動でスクロールします (手動スクロールで中断)
- 下部ナビバー: 着レス数 (NG 件数)・サイズ / リンクフィルタ (画像・動画・外部リンクを含むレスだけ表示) / Top・New・End・レス番ジャンプ

### 6.8 レスの右クリックメニュー

選択テキスト・ID・名前のハイライト (15色) / ハイライト解除 / 画像を保存 / URL・テキスト・本文・レス URL・ID のコピー / ここにレス (引用)・名前付き引用 / スレ全体をコピー / NG ワード・NGID・NG 名前に追加 / AA 表示切替 / このレスから読み上げ / このレスから新着として流す / 自動更新・自動スクロール・読み上げのトグル

## 7. 検索 (レス抽出 / スレ内検索)

スレタイトルバーの検索ボタンから 2 モードを選べます。

### 7.1 レス抽出

キーワードに合致するレスだけを表示します。ID・ワッチョイのメニューからも「このIDでレス抽出」できます。

### 7.2 スレ内検索

ヒット件数 (n/m) を表示し、↑↓ボタンまたは Enter で次のヒットへジャンプ。ヒット箇所はハイライトされます。

検索履歴はスレ検索と別に最大 20 件保存され、ドロップダウンから再利用できます (右クリックで削除)。

## 8. 書き込み

書き込みには2つの方法があります。**下部の書き込みウィンドウ**（レス専用）と、**書き込みの浮遊ウィンドウ**（レス・新スレ立ての両方）です。

### 8.1 下部の書き込みウィンドウ（レス専用）

1. ファイルメニュー「書き込み」で開く（レスのみ。折りたたみ部分をクリックすると展開・格納します）
2. 名前 (入力履歴 datalist 付き)・メール・sage・本文を入力。**sage** チェックでメール欄が sage 固定になります
3. 「本文」タブと「プレビュー」タブを切り替えられます。プレビューは実際に投稿された後の見た目（レス番号・日時・IDは仮の値）をそのまま確認できます
4. 「送信」ボタン、または **Shift+Enter / Ctrl+Enter** (設定で選択) で送信

- 名前・メール・sage・文字数/行数カウンタ・送信ボタンは同じ行にまとまっています
- ウィンドウの高さはドラッグで調整でき、記憶されます
- 投稿に成功すると自動で再取得し、自分の投稿には [自分] ラベルが付きます

### 8.2 書き込みの浮遊ウィンドウ（レス・新スレ立て）

スレッドタイトルバーの書き込みボタンから、独立したウィンドウを開きます。字幕ウィンドウなどと同じ別ウィンドウなので、他のウィンドウの上に出したまま操作できます。

- 「レス」「新スレ」を切り替えて、レス・新スレ立てのどちらも行えます (5ch / したらば / JPNKN 対応)
- 投稿先は、このウィンドウを開いた時点でアクティブだったスレ・板に固定されます（開いたまま別のタブに切り替えても投稿先は変わりません）
- 投稿・スレ立てに成功すると、ウィンドウは自動的に閉じます
- このウィンドウを開いている間、レスのダブルクリックによる引用はこちらに反映されます

### 8.3 引用

- レスをダブルクリック → `>>N` を本文に挿入（浮遊ウィンドウを開いているときはそちらに挿入されます）
- 右クリック「ここにレス」/「名前付き引用」も使えます

### 8.4 新スレ立て（板一覧からのダイアログ）

上記の浮遊ウィンドウのほか、スレ一覧ツールバーの「スレ立て」からもダイアログを開いて作成できます。スレタイ・名前・メール・本文を入力して作成します。5ch / したらば / JPNKN すべてに対応。成功すると新しいスレがタブで開きます。

### 8.5 書き込み履歴

ファイルメニュー「書き込み履歴」で、日時・成否・返信/スレ立て・スレ名・本文冒頭を最大 50 件確認できます。
履歴は `data/post-history.json` に保存され、再起動しても残ります。

### 8.6 確認画面の自動処理

書き込み時の確認画面 (同意フォーム等) は自動処理されます。BE / UPLIFT / どんぐり等のログイン認証機能は搭載していません。

## 9. NG フィルタ

### 9.1 種類

| タイプ | 対象 |
|--------|------|
| ワード | 本文 |
| ID | レスの ID |
| 名前 | 投稿者名 |
| メール | メール欄 |
| スレタイ | スレ一覧のタイトル |
| 画像NG | 本文 (一致したレスの画像だけを非表示にする専用カテゴリ) |
| 見えない文字 | 名前と本文 (下記「見えない文字を含むレス」) |

- **正規表現**: ワード NG に限り、追加フォームの入力形式で「正規表現」を選ぶと `/pattern/` 形式として登録されます (大文字小文字無視)。他の種類でも `/pattern/` の形式で直接入力すれば正規表現として認識されます
- **スコープ**: 全体 / この板 / このスレ (スレタイ NG には「このスレ」はありません)

#### 見えない文字を含むレス

名前か本文に、画面に見えない文字を 1 つでも含むレスを NG にします。NG パネルの一覧の先頭、または
設定 > NG の「見えない文字」タブで、「NG にしない (既定) / 通常あぼ～ん / 透明あぼ～ん」から選びます。
範囲は全体のみで、通常あぼ～んの理由表示は「NG: 見えない文字」です。

- 対象: 幅ゼロの空白 (U+200B)・幅ゼロの非接合子 (U+200C)・単語結合子 (U+2060)・BOM (U+FEFF)、
  文字の向きを変える制御文字 (U+200E/200F、U+202A〜202E、U+2066〜2069)、
  空白に見えるハングルの埋め文字 (U+115F/1160/3164/FFA0)
- 対象外: 合成絵文字 (👨‍👩‍👧 など) に使う U+200D と、❤️ などに使う異体字セレクタ (U+FE00〜FE0F)
- `&#8203;` のような文字参照で書かれていても判定します

### 9.2 モード (項目ごとに選択)

NG の効き方は**項目 1 件ごと**に選べます (画像NG を除く)。同じワード NG でも、あるワードは
透明あぼ～ん、別のワードは通常あぼ～んに、というように個別に設定できます。登録時のドロップダウンで
選ぶほか、登録済みの項目も NG パネル・設定パネルの一覧から後で変更できます。

| モード | 動作 |
|--------|------|
| 透明あぼ～ん | レスをまるごと非表示にする (従来の NG の挙動) |
| 通常あぼ～ん | レスは残すが、名前・メール欄・投稿日を「あぼ～ん」に、本文を理由表示付きの「あぼ～ん」に置き換える |

**画像NG** は上記のモードとは別の独立したカテゴリです。本文に指定した単語を含むレスの画像だけを
非表示にし、レス自体や本文は通常どおり表示されます。モードの選択はなく、一致すれば常に画像だけが
隠れます。

**通常あぼ～ん**のレス本文には点線の下線が付き、マウスオーバーすると一致した NG 内容
(例:「NGワード: ○○」) がツールチップで表示されます。この理由表示は「登録項目のマスク」設定の
対象外で、常にそのまま表示されます。

### 9.3 登録方法

- 設定 > NG の各節 (ワード・ID・名前・メール・スレタイ) の「この節のすべてを 通常あぼ～んにする / 透明あぼ～んにする」で、その節の登録をまとめて切り替えられます (確認が出ます)


- ツールバーの「NG」ボタンで NG パネルを開いて追加・削除 (この画面では種類をプルダウンで選びます)
- レスの右クリックメニューから選択テキスト・ID・名前を即 NG
- スレ一覧右クリック・BE メニュー・ワッチョイメニューからも追加可能
- 設定パネルの NG カテゴリでも一覧管理できます。種類ごとに節タブが分かれており、開いている節タブの
  種類で追加されます (種類を選ぶプルダウンはありません)

### 9.4 新着ペイン・字幕・読み上げでの扱い

- **透明あぼ～ん**のレスは、従来どおり新着ペイン・字幕・読み上げのすべてから除外されます。
- **通常あぼ～ん**のレスは新着ペイン・字幕にも表示され、名前・メール・投稿日・本文が同じように
  「あぼ～ん」に置き換わります (新着ペイン・字幕では理由のツールチップは出ません)。
- 読み上げは、設定パネルの NG タブにある「通常あぼ～んを『あぼーん』と読み上げる」で切り替えられます
  (既定 ON)。ON のときはレス番号を読んだ後に本文の代わりに「あぼーん」と読み上げ、OFF のときは
  透明あぼ～んと同様にレス番号ごと読み上げをスキップします。

## 10. ハイライト

- **15色パレット** から色を選んで、ワード (本文)・名前・ID を色分けできます
- レスの右クリック → ハイライトサブメニューの色グリッドで即適用
- 設定パネルのハイライトカテゴリで一覧管理・全削除
- **ID ハイライトは当日限り有効** (日付が変わると自動リセット)
- ハイライトは字幕ウィンドウにも反映されます

## 11. 実況機能

### 11.1 新着レスペイン

- レスペイン右側に表示されるサブパネルです。自動更新で取得した新着レスを 1 件ずつ順番に表示します
- 表示中のスレ以外 (バックグラウンドのタブ) の新着も流れます
- 長い本文は少し静止したあと、ゆっくり自動スクロールして全文を見せます
- レスをクリックすると該当スレ・レスへジャンプ
- 操作のボタンはアドレスバーの右にあります: ▶ 次の新着レスを表示 / 字幕ウィンドウの開閉 / クリア (待ち行列と表示中のレスを消す) / 「新着レス」で新着レスペインの開閉
- ビュワーのタブでは新着レスペインを出しません (ビュワーの下に最新レスの欄があるため)。ほかのタブに移ると、元の開閉の状態で出ます。閉じていても、新着の処理・字幕・読み上げは動きます
- 高さはドラッグで調整できます
- リンクカードは画面の少し手前から読み込みます。読み込みでカードの高さが変わっても、見ているレスの位置は動きません (一度取ったカードは、次からすぐに表示します)

### 11.2 字幕ウィンドウ

字幕ウィンドウの大きさは、字幕をオフにしたときとアプリの終了時に覚え、次にオンにしたとき (再起動後も) 同じ大きさで開きます (位置はアプリの起動中だけ覚えます)。

- 半透明・最前面の別ウィンドウに新着レスを表示します (配信画面に重ねる用途)
- スレタイトルバーまたは新着ペインの字幕ボタンで ON/OFF
- ドラッグで自由に移動できます
- 設定 (字幕カテゴリ): 本文フォントサイズ (10〜96) / メタ情報サイズ (8〜48) / 背景の透明度 (0〜1。0 で背景が完全に透明になり文字だけが出る) / 常に最前面 / ID の文字サイズ補正・フォント / 位置リセット
- ID 色分け・ワードハイライトが字幕にも反映されます

### 11.3 音声読み上げ (TTS)

新着レスを自動で読み上げます。スレタイトルバーの読み上げボタン、または設定パネルで ON/OFF。

| エンジン | 説明 |
|---------|------|
| SAPI | Windows 標準の音声合成。ボイス選択・速度 (-10〜+10)・音量 (0〜100) |
| 棒読みちゃん | RemoteTalk.exe のパスを設定して連携 |
| VOICEVOX | ローカルの VOICEVOX (既定 `http://127.0.0.1:50021`) と連携。話者選択・速度・ピッチ・抑揚・音量 |

- 最大読み上げ文字数 (0=無制限)。超過分は「長文のため以下省略」と読まれます
- URL は除去 (YouTube は「ユーチューブ」と読み上げ)、HTML タグ・エンティティは除去されます
- レス番号の前置きはサイト別 (「レスN番さん」「したらばN番さん」「ジャパンくんN番さん」)
- 右クリック「このレスから読み上げ」で途中から連続読み上げできます
- 右クリック「このレスから新着として流す」で、そのレスから後を新着レスとして新着レスペイン・字幕に流せます (読み上げはしません)。
  配信ホワイトリストの ID のレスは、本物の新着と同じくビュワー・OBS 表示にも流れます

### 11.4 読み上げ辞書

設定パネル「読み上げ辞書」で、キーワード → 読み方の置換を登録できます。
「全置換」を有効にすると、キーワードを含むレス全体を指定テキストに置き換えて読み上げます。

### 11.5 OBS 連携 (廃止)

以前の「OBS連携」(専用ウィンドウを OBS のウィンドウキャプチャで取り込む方式) は廃止しました。
代わりに、OBS の「ブラウザ」ソースで表示する **OBS 表示** を使ってください (11.7 節)。
OBS 側は、「ウィンドウキャプチャ」のソースを消して「ブラウザ」ソースを追加し、URL に `http://127.0.0.1:11290/overlay.html` を入れます。
配信ホワイトリストはそのまま使えます (設定 > ビュワー >「ホワイトリスト」)。

### 11.6 Twitch チャット

アドレスバーに `twitch.tv/チャンネル名` (または `https://www.twitch.tv/チャンネル名`) を入れて移動すると、
「Twitch #チャンネル名」タブが開き、そのチャンネルのチャットが届くたびにレスとして表示されます。

- 受信にログインは不要です (Twitch の匿名の受信用の仕組みを使います)。書き込むには Twitch へのログインが要ります (下の「書き込み」)
- 1件のチャットが1レスになります。名前欄は表示名、ID 欄にはログイン名が入ります。そのため、
  ID の NG・ID のハイライト・書き込み回数の表示・配信ホワイトリストが、掲示板と同じように使えます
- ワード・名前などの NG、見えない文字の NG、ハイライトも効きます
- 新着レスペイン・字幕・ビュワー・OBS 表示・読み上げにも流れます。読み上げは「表示名さん」に続けて本文を読みます
  (設定 > Twitch で名前を読まないようにもできます)
- **書き込み**: Twitch のタブを開いているときは、下の書き込み欄からそのチャンネルのチャットに書き込めます
  (設定 > Twitch > ログイン で Twitch にログインしておく必要があります。以前の版でログインした人は「ログインし直す」を押してください)。
  - 書き込み欄の上の行に **送信先 (Twitch #チャンネル名) と、ログインしているアカウント**・文字数を表示し、欄の色も紫になります。その右に「スタンプ」ボタンと送信ボタン (送信先入り) があり、その下が書き込む欄です (スレの書き込み欄と同じ並び)
  - **送る前に毎回、送信先と本文を確認します** (設定 > 書き込み でオフにできます)。確認は Enter で送信・Esc でキャンセルできます
    (確認ダイアログはどれも Esc で閉じられます。削除など取り消しのきかないボタンだけのダイアログは、Enter では決定しません)
  - 送るのは **Ctrl+Enter か送信ボタン**だけです。Enter では送りません (改行もしません)
  - 書き込み欄の中身はタブごとに別々です。タブを切り替えると欄の中身も入れ替わるので、ほかのタブ (掲示板など) で書いた文がチャットに送られることはありません
  - **スタンプ**: 「スタンプ」ボタン (送信ボタンの左隣) で、自分が使えるスタンプ (グローバル・サブスク・フォロワー限定など) の一覧を、書き込み欄の上 (ウィンドウの右端) に開きます。
    チャンネルごとに見出しの帯で分け、下の切り替えで「最近使ったもの / このチャンネル / すべて / グローバル / 絵文字」を選べます。名前で絞り込めて、押しても一覧は開いたままなので続けて選べます (Esc・一覧の外を押すと閉じます)。
    フォロワー限定のスタンプは、そのチャンネルのタブでだけ出ます (Twitch の決まりで、そのチャンネルでしか使えないため)。
    本文にスタンプの名前を書いても画像になります。Tab キーでスタンプの名前を補完でき、送る前の見た目 (スタンプを画像にしたもの) を欄の下に表示します
  - **絵文字**: 「絵文字」ボタンの一覧から入れられます。Windows の絵文字パネル (Win + .) も使えます
  - **返信**: コメントを右クリック →「このコメントに返信」で、Twitch の返信として送れます
  - **@メンション**: `@` に続けて名前の頭を入力して Tab を押すと、このタブで書き込んだ人の名前を補完します
  - 1件 500 文字まで、30 秒に 20 件までです。BAN・タイムアウト・フォロワー限定などで送れないときは、その理由を表示します
  - ビッツの応援・巨大スタンプ (パワーアップ)・`/` で始まるコマンドは使えません
  - 書き込み欄の浮遊ウィンドウからはチャットに送れません (送信先を取り違えないよう、下の書き込み欄に絞っています)
- 自動更新の設定に関係なく、届いたチャットはすぐに表示されます
- 1つのタブに残すのは新しい 1000 件までです。流れの速いチャンネルでは、新着レスペイン・字幕は新しいチャットを優先し
  (溜めておくのは既定で 10 件まで)、読み上げも溜まりすぎているとき (既定で 10 件以上) は新しいチャットを読み上げに加えません。
  どちらの件数も 設定 > Twitch で変えられます
- タブを閉じると受信を止めます。同時に受信できるのは 20 チャンネルまでです
- Twitch のタブでは、栞・スクロール位置・スレのキャッシュは保存しません (セッションの復元ではタブだけが戻り、受信をやり直します)
- 通信先は Twitch のチャット用サーバー (`irc-ws.chat.twitch.tv`) だけです
- **イベント**: サブスク・継続サブスク・サブスクギフト・まとめてギフト・ギフトの継続・ビッツ・レイド・連続視聴・
  チャンネルポイント (メッセージを入力する報酬)・アナウンスを、「【種類】要約」の1件として表示します。ビュワー・OBS 表示では目立つ色で出ます。
  設定 > Twitch >「イベント」で、種類ごとに流す・読み上げる・読み上げる文 ({name} {months} {count} {bits} {viewers} {recipient} {reward} {message}) を変えられ、
  「テスト」で開いている Twitch タブに試しのイベントを流せます。ログインなしで表示できるのは、サブスク・ギフト・ビッツ・レイド・連続視聴・
  **入力つきの**チャンネルポイント報酬・アナウンスです。入力の無い報酬・自動報酬 (メッセージのハイライトなど)・フォローは、
  設定 > Twitch >「Twitch にログイン」で**配信者本人のアカウント**でログインすると、そのチャンネルの分だけ表示できます
  (TchViewer と同じ方式。そのチャンネルの Twitch タブを開いておくと、タブとビュワー・OBS 表示に流れます)
- **Twitch へのログイン (任意。書き込みには必要)**: 「Twitch にログイン」を押すとブラウザで Twitch の確認ページが開くので、設定画面に出たコードを入力して許可します
  (確認ページに表示されるアプリ名は LiveFake 用に登録したものです)。
  求める許可は、チャンネルポイントの引き換えとフォロワーの読み取り・チャットへの書き込み・自分が使えるスタンプの一覧の読み取りです。ログイン情報は Windows の機能で暗号化して `data/twitch-auth.bin` に保存し、
  別の PC や別の Windows ユーザーでは読めません。「ログアウト」で Twitch 側の許可も取り消して削除します。
  ログイン中は、自分のチャンネルのチャンネルポイントはログインの側で受け取り、チャットでは普通の発言として扱います (二重に出ないように)
- **スタンプ**: チャットのスタンプを画像で表示します (Twitch タブ・ビュワー・OBS 表示)。ビッツのパワーアップで巨大化したスタンプは大きく表示します。
  大きさは 設定 > Twitch >「スタンプ」(Twitch タブ・ビュワー) と、OBS 表示のレイアウト (スタンプ・巨大化したスタンプ・バッジ) で変えられます。
  読み上げでは名前 (Kappa など) のまま読み、同じスタンプは既定で3個まで (1〜10個で変えられます) にします (「読まない」も選べます)。
  新着レスペインと字幕ウィンドウにもスタンプとバッジを出します (字幕のスタンプの大きさは 設定 > Twitch > スタンプ)
- **掲示板に書かれたスタンプ名**: 掲示板の書き込みにスタンプ名 (例: `Kappa`) がそのまま書かれていると、スレのタブ・新着レスペイン・字幕・ビュワー・OBS 表示で画像にします
  (英数字の名前で、大文字小文字まで一致したものだけ)。頭に `BIG` (大文字小文字は問わない) を付けて `BIGKappa` のように書くと、
  巨大化したスタンプの大きさで表示します (LiveFake の表示だけの機能です。Twitch・掲示板の他の人の画面では文字のままです)。
  スタンプの対応表とバッジの一覧は、Twitch の開発者向け規約 (保存は24時間のキャッシュまで) に合わせ、24時間見かけなかった (取得し直さなかった) ものを自動で消します。名前と画像の対応は、Twitch のチャットで見たスタンプと、Twitch にログイン中は公式の窓口
  (api.twitch.tv) から取得する一覧 (開いている Twitch チャンネルとグローバルのスタンプ) から作り、`data/twitch-emotes.json` に保存します。
  設定 > Twitch > スタンプ・バッジ でオフにしたり、覚えたスタンプを消したりできます。消した後も、チャットにスタンプが流れれば自動で覚え直し、
  ログイン中は「今すぐ取得」で一覧をまとめて取り直せます
- 設定 > Twitch は「受信・読み上げ / スタンプ・バッジ / イベント / 教育・忘却 / ログイン」の節に分かれています。
  字幕のスタンプの大きさは 設定 > 字幕 > 表示 にあります。
  新着レスペイン・字幕の見出しに Twitch のバッジを出すかは、それぞれの見出しの項目 (「Twitch のバッジ」) で切り替えられます
- **教育・忘却コマンド** (既定オフ。設定 > Twitch > 教育・忘却コマンド): Twitch のチャットの `教育(単語=読み)` / `忘却(単語)` (全角の（）＝も可) で、
  読み上げの読み方を登録・削除できます。Twitch の視聴者なら誰でも使え、視聴者ごとに5秒に1回までです。掲示板の書き込みのコマンドは受け付けず、読み上げからも除きます。
  実際に読み上げに回った発言だけが対象です。
  - 連携先が **VOICEVOX・SAPI** のとき: LiveFake の「Twitch 教育辞書」に登録し、掲示板を含むすべての読み上げにかけます
    (あなたの読み上げ辞書が優先で、その語は上書きできません。単語は30文字・読みは50文字・500件まで)。
    一覧は読み上げ辞書と同じ表で、絞り込み・修正・手での追加・削除ができます。
    「〇〇を覚えました」「〇〇を忘れました」と読み上げます (オフにもできます)
  - 連携先が **棒読みちゃん** のとき: 二重に教育されないよう LiveFake では覚えず、コマンドを棒読みちゃんにそのまま渡します
    (棒読みちゃん側で教育・忘却のタグを有効にしておく必要があります。登録内容は棒読みちゃんの辞書で管理します)
- **バッジ**: 視聴者のバッジ (配信者・モデレーター・サブスクなど) をビュワーと OBS 表示に出します。バッジの画像の一覧とチャンネルポイント報酬の名前は、
  Twitch のサイト自身が使っている取得口 (`gql.twitch.tv`。公式に公開されたものではありません) から、チャンネルが変わったときと1時間ごとに取得します
  (送るのはチャンネル名だけ。一覧は `data/badges-cache.json` に控えます)。Twitch 側の変更で使えなくなることがあります。
  設定 > Twitch >「バッジ」でオフにでき、オフにすると報酬名は「チャンネルポイント報酬」になります

### 11.7 ビュワーと OBS 表示

板タブの左端の「ビュワー」を押すと、**Twitch・YouTube のチャット**と、**配信ホワイトリストに入れた ID の掲示板のレス**を、
1本の流れにまとめて表示します。

- 上部で、出どころ (Twitch / YouTube / 5ch / したらば / JPNKN) ごとの表示、最新レス欄、自動スクロールを切り替えられます。
  掲示板の新着の読み上げ方 (全文 / レス番のみ) は、どのタブを開いていても切り替えられるよう、アドレスバーの行の「読み上げ:」にあります
- 項目をクリックすると、そのタブのレスへ移動します
- 下の「スレの最新レス」欄には、開いているスレの新着のうち、ホワイトリストに無い ID のレスを表示します (OBS には出ません)。
  「WLに入れる」でその ID をホワイトリストに入れられます。欄の上端をドラッグすると高さを変えられます (次回も引き継ぎます)
- **配信ホワイトリスト**: レスを右クリック →「配信ホワイトリストに追加」、または 設定 > ビュワー >「ホワイトリスト」で ID を入力して追加します
  (空白・改行・カンマ区切りで複数可)。日本時間の今日の分は保存され、日付が変わると空に戻ります
- **自動追加**: 設定 > ビュワー >「ホワイトリスト」で単語を登録すると、その単語を本文に含むレスの ID を自動でホワイトリストに入れます
  (部分一致、/…/ で正規表現。1日の上限 既定 20 件。今日手で外した ID は入れ直しません)
- **リンクカード・画像**: Twitch・YouTube のチャットと掲示板のレスのリンクを、レス表示欄と同じようにリンクカード・画像のサムネイルで表示します
  (設定 > ビュワー >「表示」でそれぞれオンオフ。カードは画面に入ったものだけ読み込みます)。リンクはクリックでブラウザ、サムネイルはクリックで画像ウィンドウで開きます。
  **OBS 表示には出しません** (配信に不適切な画像・リンクが映らないように。OBS 表示では本文は文字のままです)。
  画像・カードを読み込むと、リンク先のサーバーにこの PC の IP アドレスが伝わります。Twitch・YouTube のチャットの分は「クリックしてから読み込む」にもできます。
  LiveFake の画面ごと配信に映している場合は画像も映るので注意してください。画像NG・サイズ上限・URL の置き換えルール・カードのドメインの許可/拒否も効きます
- **表示する項目**: 設定 > ビュワー >「表示」で、見出しの項目をそれぞれ表示/非表示にできます。配信ホワイトリストのレスは プラットフォーム・板・スレタイ・レス番・名前・メール欄・日時・ID・書き込み回数 の順に並びます
  (書き込み回数の色はスレのタブと同じ。Twitch・YouTube のチャットは プラットフォーム・チャンネル・バッジ・名前・ID・日時)。
  下の「スレの最新レス」欄は 板・スレタイ・レス番・本文・日時・ID・書き込み回数 の順に1行で並び、それぞれ表示/非表示にできます (1行に収まらないときは本文を省きます)
- **文字**: 設定 > ビュワー >「表示」で、ビュワーと最新レス欄の文字サイズ・フォント・太字を変えられます
  (文字サイズ 0 ならレスの文字サイズに、フォントが空ならアプリ全体のフォントに合わせます)
- **読み上げ方** (アドレスバーの行の「読み上げ:」、または 設定 > 読み上げ): 「全文を読む」か「ホワイトリスト以外はレス番のみ」(ホワイトリストの ID は本文まで、それ以外は「レスN番さん」だけ) を選べます
- **登録項目のマスク**: 設定 > ビュワー >「ホワイトリスト」の「登録項目のマスク」をオンにすると、ホワイトリストの ID・自動追加の単語・
  今日外した ID の表示を伏せます (配信画面に設定を映すとき用)。設定 > 表示・読み上げ辞書・NG の「登録項目のマスク」と同じ設定で、どこで切り替えても連動します

**OBS 表示**: 設定 > ビュワー >「OBS 表示」で「OBS 表示を使う」をオンにし、OBS の「ソース」→「ブラウザ」の URL に
`http://127.0.0.1:11290/overlay.html` を入れると、ビュワーと同じ内容が OBS に出ます。

- このPCの中からだけ見られます (ポート開放は不要です)。ポートは変更できます (既定 11290)
- LiveFake を更新すると、OBS 表示のページは次につながったときに自動で新しいページに読み込み直します (OBS で「現在のページのキャッシュを更新」を押す必要はありません)
- 「OBS 表示を使う」は切り替えた時点で保存され、LiveFake を起動し直しても引き継ぎます
- 表示件数・消えるまでの秒数・積む向き・縁取り・掲示板/Twitch ごとの文字サイズ・色・背景・表示する項目 (Twitch はバッジも) を設定できます
  (YouTube のチャットは Twitch と同じ見た目で、出どころの色だけ赤になります)
- 「テスト表示」で見た目を確かめられます
- **レイアウト**: 見た目に名前を付けて複数保存できます。「編集するレイアウト」のプルダウンで切り替えて編集し、
  名前を入れて「新規」(既定の見た目) /「複製」(選んでいるレイアウトの写し) で増やせます (名前が空なら「レイアウト 1」「標準 のコピー」のように自動で付けます)。「名前を変更」「削除」もできます (「標準」は消せません)。
  レイアウトを選ぶと上の URL に `?layout=名前` が付くので、OBS のソースごとに別の URL を入れれば見た目を使い分けられます。
  無いレイアウト名を指定したソースは「標準」の見た目になります
- **追加 CSS**: レイアウトごとに CSS を書けます (そのレイアウトだけに効きます)。主なクラスは `.msg` (1件)・`.board` / `.twitch` / `.youtube` (出どころ)・
  `.s-5ch` / `.shitaraba` / `.jpnkn`・`.badge` `.meta` `.no` `.name` `.uid` `.text` です。書き換えは表示中の OBS にもすぐ反映されます
- レイアウトは `data/overlay-layouts.json` に保存します (以前の見た目の設定は「標準」に引き継ぎます)

### 11.8 接続とタブごとの読み上げ

設定 >「接続」で、Twitch のチャンネル・YouTube のライブ配信・スレをまとめて追加できます (追加するとタブが開きます。開いているタブがそのまま巡回・受信の対象です)。
一覧には開いているタブが並び、状態の確認、読み上げのオンオフ、開く・閉じるができます。
状態はランプ (緑=受信中・取得済み / 黄=接続中・未取得 / 赤=切断) と文字で表示し、スレには埋まり具合のバー (レス数/1000) も出します
(Twitch・YouTube には埋まりが無いので出しません)。YouTube の配信が止まったときは、理由を状態の文字に重ねると表示し、「つなぎ直す」でつなぎ直せます。

- **読み上げのオンオフ**: スレタイバーの音量のボタンは、**すべてのスレ・チャンネル**の読み上げのオンオフです。
  その隣の耳のボタン (またはタブの右クリック・設定 > 接続) で、**タブ (スレ・チャンネル) ごと**に読み上げをオフにできます
  (オフのタブには印が付きます)。「このレスから読み上げ」は自分で選んだ操作なので、オフのタブでも読み上げます

### 11.9 YouTube のライブ配信のチャット

アドレスバーに YouTube の**ライブ配信の URL** (`youtube.com/watch?v=…` / `youtube.com/live/…` / `youtu.be/…`) を入れて移動すると、
「YouTube 配信のタイトル」タブが開き、その配信のチャットが届くたびにレスとして表示されます。

- **読み取り専用**です。書き込みはできません。開けるのはライブ配信 (配信中・配信予定) だけで、チャンネルの URL・アーカイブ・普通の動画には対応していません
- **API キーが必要です** (YouTube 公式の API を使います)。次の手順で作り、設定 > YouTube に貼り付けて「保存」を押してください
  1. Google Cloud のコンソール (https://console.cloud.google.com/) でプロジェクトを作る
  2. 「API とサービス」→「ライブラリ」で「YouTube Data API v3」を有効にする
  3. 「認証情報」→「認証情報を作成」→「API キー」でキーを作る
  4. 作ったキーの「API の制限」で「YouTube Data API v3」だけを選んでおく (おすすめ。キーが漏れても他の API に使われません)

  キーは Windows の機能で暗号化して `data/youtube-api-key.bin` に保存し、YouTube の API (`www.googleapis.com`) にだけ送ります。
  画面やログには出しません。「削除」で消せます
- **1日に使える回数に上限があります**。1回の取得で 5 クォータ使い、既定の上限は1日 10,000 クォータです。
  取得の間隔 (設定 > YouTube。既定 10 秒、5〜120 秒) が 10 秒なら、配信1つを約 5.5 時間受信できます (配信を2つ開くと半分)。
  YouTube から指示された間隔のほうが長いときは、そちらに合わせます。上限に達すると受信を止めて理由を表示します。上限は太平洋時間の0時 (日本時間の16〜17時) に戻ります
- 1件のチャットが1レスになります。名前欄は表示名、ID 欄には投稿者のチャンネル ID が入ります。そのため、
  ID の NG・ID のハイライト・書き込み回数の表示・配信ホワイトリストが、掲示板と同じように使えます。名前は、配信者=黄・モデレーター=青・メンバー=緑で色分けします
- 新着レスペイン・字幕・ビュワー・OBS 表示・読み上げにも流れます。読み上げは「表示名さん」に続けて本文を読みます
  (設定 > YouTube で名前を読まないようにもできます)。絵文字 (`:名前:` の形) は読み上げません。
  新着レスペイン・字幕に溜めておく上限と、読み上げの溜まりの上限は、設定 > Twitch と同じ値を使います
- 最初につないだときに見える「つなぐ前の発言」は流しません (つないだ後の発言だけ)
- **イベント**: スーパーチャット・スーパーステッカー・メンバー加入・メンバー継続・メンバーシップのギフト・ギフトの受け取り・ジュエルのギフトを、
  「【種類】要約」の1件として表示します。金額は表示するだけです。設定 > YouTube >「イベント」で、種類ごとに流す・読み上げる・読み上げる文
  ({name} {amount} {months} {count} {level} {item} {message}) を変えられ、「テスト」で開いている YouTube タブに試しのイベントを流せます
- **削除された発言**: 配信者・モデレーターが消した発言 (ブロックした視聴者の発言を含む) は、タブでは「（削除されました）」になり、
  まだ流していない新着レスペイン・ビュワー・OBS 表示からも消えます
- チャンネル独自の絵文字は、YouTube の画像配信サーバーから取れるときは画像で表示します
- タブを閉じると受信を止めます。同時に受信できるのは 10 配信までです。止まった・終わった配信は、設定 > 接続 の「つなぎ直す」でつなぎ直せます
- YouTube のタブでは、栞・スクロール位置・スレのキャッシュは保存しません。チャットは保存しません (タブを閉じる・終了すると消えます)
- 設定 > YouTube に、YouTube 利用規約と Google プライバシー ポリシーへのリンクがあります

## 13. CSS カスタマイズ

UI の見た目は `data/custom.css` に CSS を書くことで自由に変更できます。

- 初回起動時に説明コメント付きのテンプレートが自動生成されます

## 17. よくある質問

### Q. 新しいバージョンが出たら分かりますか

設定 > 情報「起動時に新しいバージョンを確認する (1日1回)」がオン (既定) なら、起動時に1日1回だけ公開している最新版の情報を確認し、
新しい版があればステータスバーに表示して、ヘルプメニューに印を付けます。オフにすると、ヘルプ > バージョン情報 を開いたときだけ確認します。

### Q. 自動更新が効かない

ツールバーの「自動更新」チェックが ON か確認してください。間隔は設定「自動更新間隔」(10〜300秒) で変更できます。

### Q. 字幕ウィンドウが表示されない

スレタイトルバー (または新着ペイン) の字幕ボタンが ON か確認してください。画面外に出てしまった場合は設定「字幕」の位置リセットを使ってください。

### Q. dat 落ちしたスレを読みたい

一度でも開いたスレは `cache.db` にキャッシュされています。スレ一覧ツールバーの「dat落ちキャッシュ」ボタンで一覧表示できます。

### Q. 設定や履歴を別の PC に移したい

EXE と同じフォルダの `data/` をまるごとコピーしてください。

### Q. 見た目を元に戻したい

`data/custom.css` の中身を空にして「設定 > ユーザーCSSを再読み込み」を実行してください。

### Q. プロキシを使いたい (2chAPIProxy など)

設定 >「プロキシ」で設定し、「保存」を押すと次の通信から使います (JaneXeno のプロキシ設定に近い並びです)。

- **Proxy を使う**: オンにするとプロキシを使います
- **Proxy 使用時にキャッシュを使用しない**: プロキシに古い控え (キャッシュ) を返さないよう頼みます
- **種類**: HTTP / SOCKS5 / SOCKS4。SOCKS は名前の問い合わせ (DNS) もプロキシに任せます
- **受信用**: 掲示板 (5ch・したらば・JPNKN) の板一覧・スレ一覧・レスの読み込みに使うプロキシ
- **送信用**: 書き込み・スレ立てに使うプロキシ
- ホストには `http://` を付けずにホスト名か IP アドレスだけ (例: `localhost`)、ポートは数字だけ (例: `8080`) を入れます。
  認証の要るプロキシだけユーザー名・パスワードを入れます (パスワードは Windows の機能で暗号化して保存)。ホストが空欄の欄はプロキシを通しません
- 画像・リンクカード・Twitch・YouTube・更新の確認はプロキシを通しません

**2chAPIProxy を使う場合**: 種類を HTTP、受信用・送信用のホストを `localhost`、ポートを 2chAPIProxy の画面のポート番号 (例: `8080`) にし、
「5ch の通信を http でプロキシに渡す」をオンにします。2chAPIProxy は https の通信を素通しするため、5ch の読み込み・書き込みを
2chAPIProxy に処理させるには、http (5ch.net の形) で渡す必要があるためです (種類が HTTP でホストが localhost / 127.0.0.1 の欄だけに効きます)。

- 2chAPIProxy の「2chへのアクセスにhttps(TLS)を利用する」を必ずオンにしてください。オフだと、書き込みの内容や Cookie が暗号化されずにネットに出ます
- 5ch.io への移転に対応した版 (2026.03.07 以降) の 2chAPIProxy が必要です。古い版では 5ch の読み込みがリダイレクトを繰り返してうまくいきません
- 2chAPIProxy の「ポートを自動選択」をオンにすると起動のたびにポート番号が変わるので、オフにしておきます
