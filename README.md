# LiveFake

**実況向け掲示板ブラウザ＋Twitch・YouTube チャットビュワー** — Tauri v2 (Rust) + React デスクトップアプリ

5ch.io / したらば / JPNKN の3サイトに対応した Portable 形式の実況専用ブラウザです。
Twitch のチャットと YouTube のライブ配信のチャットも、スレと同じ形で表示・読み上げ・書き込みができます。
ZIP を展開するだけでインストール不要で使えます。

### 前回 (v0.0.121) の更新内容

**YouTube のチャットに書き込めるようになり、API の使用量 (クォータ) を見ながら長い配信でも受信できるようになりました。**

#### YouTube

- **チャットへの書き込み (任意)**: YouTube タブの下の書き込み欄から書き込めます。200 文字まで・絵文字の一覧あり・Ctrl+Enter で送信 (Enter では送りません)。
  Twitch と同じく送る前に毎回確認し、自分の書き込みはすぐタブに出ます。1回の書き込みで API の使用量を 20 使います
  - 使うには、**自分の Google Cloud プロジェクトに OAuth クライアント (種類「テレビと入力が限られたデバイス」) を作り**、設定 > YouTube > 書き込み に ID とシークレットを入れて「Google にログイン」します
    (同意画面を「外部」で作り、テストユーザーに自分のアカウントを追加します。手順は設定画面と [説明書](https://github.com/kaedekiku/LiveFakeTauri2/blob/main/docs/USER_MANUAL.md) にあります)
  - 「アクセスをブロック」(エラー 403: access_denied) と出たら、テストユーザーに自分のアカウントが入っていません。同意画面が「テスト」のままだと、7 日でログインが切れます (もう一度ログインすれば使えます)
  - **このログインで与える許可 (YouTube アカウントの管理) は、チャットへの書き込みだけでなくチャンネルの操作全体に及びます。** LiveFake はチャンネル名の確認・チャットの ID の確認・書き込みにしか使いませんが、
    心配なときは書き込み用のサブのチャンネル (ブランド アカウント) でログインしてください。ログイン情報は暗号化してこの PC に保存します
- **API の使用量の目安**: YouTube タブのタイトルの帯とビュワーの上の段に「▶ YouTube API 使用量 / 上限 (%)」を出します。80% で橙・95% で赤になり、お知らせも出ます。押すと設定が開きます
- **長い配信に合わせてコメントを読み込む間隔を自動で決める**: 設定 > YouTube > 使用量・間隔 で「決めた時間もつように」を選び、「もたせる時間」(配信の予定時間) を入れると、
  1 日の上限 (既定 10,000。日本時間の16時 (冬は17時) に戻る) の残りを割り振って間隔を延ばします (例: 上限が戻った直後に 8 時間なら 15 秒ごと)。
  値を変えると「実際に読み込む間隔」がその場で変わり、青く光って示します
- **受信できない理由を知らせる**: youtube.com のトップやチャンネルの URL を入れたとき、開いた配信が普通の動画・終わった配信・チャットがオフだったときに、理由をダイアログで出します。
  受信が止まっているタブには、理由の帯と「つなぎ直す」「タブを閉じる」が出ます
- 「取得の間隔」を「コメントを読み込む間隔」に改め、設定 > YouTube を節タブ (受信 / 使用量・間隔 / 書き込み / 読み上げ / イベント) に分けました

#### 新機能

- **ビュワーの「選んだスレを流す」**: 設定 > 接続 の「ビュワー」のチェック (またはタブの右クリック) で選んだスレのレスを、ホワイトリストに関係なくビュワーに流します (開いたスレは既定で選ばれています。OBS 表示には今までどおりチャットとホワイトリストの分だけ)
- **字幕の枠**: 「通常 / 四隅だけ / 枠なし」から選べます (設定 > 字幕 > 枠・大きさ)。幅・高さの数値での指定、字幕の上の右クリックからのメニューも追加。文字の影 (ドロップシャドウ) もオフにできます
- **タブの幅をそろえる** (既定オン。板タブ 140px・スレタブ 180px。設定 > 表示 > 全般)

#### 変更

- ビュワーの「スレの最新レス」の欄を、新着レスペインの場所 (上の段) に移しました。開閉はアドレスバーの行の「新着レス」ボタンで行います

#### 修正

- **2chAPIProxy などのプロキシを使っているとき、5ch に同じ書き込みが2回されることがある問題**
- リンクカードが表示されたときに、下のレスの位置がずれる問題

## 主な機能

### 掲示板の閲覧

- **3サイト対応**: 5ch.io (Shift_JIS) / したらば (EUC-JP、ID 付き) / JPNKN (Shift_JIS) — エンコーディング自動判別
- **板一覧**: カテゴリーツリー表示・検索フィルタ・お気に入り板（ドラッグで並べ替え）
- **外部板登録**: したらば・JPNKN の板を URL で追加
- **スレッド一覧**: 全列ソート・検索・既読/未読管理・勢いバー・dat 落ちスレのグレーアウト表示・キャッシュ閲覧・カスタムタイトル
- **マルチタブ**: 板タブ + スレタブの2段構成。ドラッグ並べ替え・中クリックで閉じる・タブ上限設定 (既定20、変更可)
- **自動更新**: 1秒刻み (10〜300秒) で新着レスを自動取得。バックグラウンドタブも差分取得
- **セッション復元**: 前回のタブ・ウィンドウサイズ・レイアウトを次回起動時に復元

### レス表示

- アンカーポップアップ (`>>N`, `>>N-M`, `>>N,M` 対応・多段ネスト)
- ID 色分け・書き込み回数表示 (2回以上=青、5回以上=赤)・同一 ID レス一覧ポップアップ
- 被参照数表示 (▼N) とポップアップ
- 自分の投稿 [自分] / 自分宛レス [自分宛] の自動検出
- 新着マーカー「ここから新着」 / New! ラベル
- ASCII アート自動検出・等幅フォント切替 (右クリックで手動切替も可)
- 画像 URL 自動サムネイル (サイズ上限でクリックするまで非表示にする設定あり)・ホバープレビュー (ズーム対応)・別ウィンドウ表示・保存
- **リンクカード**: 本文中の URL を OGP 情報 (タイトル・説明・画像) 付きのカードで表示。X (Twitter) のポスト・YouTube 動画に対応（既定 OFF、通信先ドメイン制限あり）
- リンクフィルタ (画像 / 動画 / 外部リンクを含むレスのみ表示)
- 栞 (最後に読んだ位置) とスクロール位置の自動保存

### 書き込み

- 下部の書き込みウィンドウ（返信専用）: 名前 (履歴付き) / メール / sage、送信ショートカット (Shift+Enter / Ctrl+Enter 選択式)、投稿後の見た目を確認できるプレビュータブ
- **書き込みの浮遊ウィンドウ**: スレッドタイトルバーの「書き込み」から開く独立したウィンドウ。返信・**新スレ立て** (5ch / したらば / JPNKN) の両方に対応し、投稿成功で自動的に閉じる
- ダブルクリックでレス引用、名前付き引用（浮遊ウィンドウを開いているときはそちらに反映）
- 書き込み履歴 (最大 50 件。返信・スレ立てを記録し、再起動しても残る)

### 実況特化機能

| 機能 | 説明 |
|------|------|
| **新着レスペイン** | 新着レスを1件ずつ順番に表示するサブパネル。長文はゆっくり自動スクロール (時間・速度を調整可)。クリックで該当レスへジャンプ。 |
| **字幕ウィンドウ** | 半透明オーバーレイの別ウィンドウに新着レスを最前面表示。透明度・フォント・文字の影・スクロールバー・一時停止 (▶で再開) に対応。新着ペインとの表示同期を選択可。枠は「通常 / 四隅だけ / 枠なし」から選べ、大きさは数値でも指定できる (字幕の上の右クリックから設定を開ける)。 |
| **音声読み上げ** | SAPI / 棒読みちゃん / VOICEVOX の3エンジン対応。新着レス自動読み上げ・読み上げ辞書 (単語置換)・IP 配信 URL 用の読み上げ許可リスト・読み上げない辞書 (名前/本文/ID) 付き。 |
| **Twitch チャット** | アドレスバーに `twitch.tv/チャンネル名` を入れると、そのチャンネルのチャットをスレと同じ形で表示。新着レスペイン・字幕・読み上げ (「名前さん」+本文)・NG・ハイライト・ビュワー・OBS 表示に流れる。受信はログイン不要。Twitch にログインすると、タブの下の書き込み欄から**書き込める** (自分が使えるスタンプの一覧・絵文字・補完・返信。送る前に毎回確認)。 |
| **YouTube のライブ配信のチャット** | アドレスバーにライブ配信の URL を入れると、その配信のチャットをスレと同じ形で表示 (詳しくは下の「YouTube のライブ配信のチャット」)。 |
| **ビュワー** | 板タブの左端。Twitch・YouTube のチャットと、配信ホワイトリストの ID のレスをまとめて表示し、OBS のブラウザソース (`http://127.0.0.1:11290/overlay.html`) にも出せる。「選んだスレを流す」をオンにすると、設定 > 接続 で選んだスレのレスもホワイトリストに関係なく流す (OBS へはチャットとホワイトリストの分だけ)。ホワイトリストの直接入力・単語による自動追加、ホワイトリスト以外はレス番だけ読む読み上げ方式。上の段 (新着レスペインの場所) に「スレの最新レス」の欄。 |
| **接続・タブごとの読み上げ** | 設定 > 接続 で Twitch チャンネル・YouTube のライブ配信・スレをまとめて追加。読み上げ・ビュワーに流すかは、タブ (スレ・チャンネル) ごとにオンオフできる。 |

### YouTube のライブ配信のチャット

- **見る・読み上げる (受信)**: アドレスバーにライブ配信の URL (`youtube.com/watch?v=…` / `youtube.com/live/…` / `youtu.be/…`) を入れて移動すると、YouTube タブが開きます。
  1件のコメントが1レスになり、新着レスペイン・字幕・読み上げ (「表示名さん」+本文)・NG・ハイライト・ビュワー・OBS 表示に流れます。
  スーパーチャット・メンバー加入などのイベントは種類ごとに表示・読み上げを選べ、削除されたコメントは消えます。
  チャンネルのページ・アーカイブ・普通の動画は開けません (理由をダイアログで知らせます)。
- **API キー (必須)**: YouTube 公式の YouTube Data API v3 を使うため、Google Cloud で各自の API キーを作って 設定 > YouTube > 受信 に入れます。
  キーは Windows の機能で暗号化してこの PC に保存し、YouTube の API にだけ送ります。
- **1日の使用量 (クォータ) に上限があります** (既定 10,000。日本時間の16時 (冬は17時) に戻ります)。コメントを1回読み込むと 5 使い、10 秒ごとなら配信1つで約 5 時間半もちます。
  YouTube タブの上の帯とビュワーに「▶ YouTube API 使用量 / 上限 (%)」を出し、80% / 95% で色とお知らせで知らせます。
  設定 > YouTube > 使用量・間隔 で「決めた時間もつように」を選ぶと、配信の予定時間に合わせてコメントを読み込む間隔を自動で延ばせます (実際の間隔はその場に表示されます)。
- **書き込み (任意)**: 設定 > YouTube > 書き込み で、自分の Google Cloud プロジェクトに作った OAuth クライアント (種類「テレビと入力が限られたデバイス」) を入れて Google にログインすると、
  YouTube タブの下の書き込み欄から書き込めます (200 文字まで・絵文字の一覧・送る前に毎回確認・1回 20 クォータ)。
  **このログインで与える許可はチャンネルの操作全体に及ぶので、心配なときは書き込み用のサブのチャンネルでログインしてください**。手順は [説明書](docs/USER_MANUAL.md) にあります。

### フィルター・ハイライト

- **NG フィルター**: ワード / ID / 名前 / メール / スレタイ / 画像NG (一致したレスの画像だけ非表示)。ワードNGは正規表現対応。
  名前か本文に**見えない文字** (幅ゼロの空白・文字の向きを変える制御文字など) を含むレスも NG にできます (既定オフ)。
- **NG モード**: 項目ごとに選択可能。透明あぼ～ん (非表示) / 通常あぼ～ん (名前・メール・投稿日・本文を「あぼ～ん」表示、本文はホバーで理由表示)
- **NG スコープ**: 全体 / この板 / このスレ
- **ハイライト**: 15色パレットでワード・名前・ID を色分け (ID ハイライトは当日限り有効)。字幕ウィンドウにも同期。
- 右クリックメニューから NG 追加・ハイライト設定を即時適用

### 配信ソフトとの連携 (既定オフ)

| 機能 | 説明 |
|------|------|
| **OBS 表示** | ビュワーと同じ内容 (Twitch・YouTube のチャットと配信ホワイトリストの ID のレス) を、OBS の「ブラウザ」ソースで表示します (`http://127.0.0.1:11290/overlay.html`、このPCの中からだけ見られます)。見た目に名前を付けた「レイアウト」を複数保存でき、`?layout=名前` でソースごとに使い分けられます。レイアウトごとに追加 CSS も書けます |

詳細は [docs/USER_MANUAL.md](docs/USER_MANUAL.md) 11.7 節を参照してください。以前の「OBS連携」(専用ウィンドウをキャプチャする方式) は廃止しました。

### 設定・カスタマイズ

- ライト / ダークモード
- タブの幅をそろえる (既定オン。板タブ・スレタブの幅を数値で指定)
- フォント・各ペイン文字サイズ・レス間隔・レスヘッダの表示項目などをGUIで細かく調整
- 設定画面は節タブ・検索窓・保存ボタン・プリセット・自動バックアップ・リセットに対応（詳細は [docs/USER_MANUAL.md](docs/USER_MANUAL.md) 14章）
- **ユーザー CSS**: `data/custom.css` / `data/theme/` で UI の見た目を自由にカスタマイズ（SIKI 互換） → [CSS カスタマイズガイド](docs/CSS_CUSTOMIZE.md)
- 画像 URL 置換ルール (`ImageViewURLReplace.txt`) でサムネイル変換をカスタマイズ
- 検索窓・スレ立てなどの入力欄は過去入力を候補表示 (履歴は設定からまとめて消去可)

- **プロキシ**: 掲示板の読み込み (受信用) と書き込み (送信用) で別々に指定できます (HTTP / SOCKS5 / SOCKS4)。2chAPIProxy などのローカルプロキシに 5ch の通信を処理させることもできます

## CSS で見た目を変える

LiveFake は UI 全体をユーザーの CSS で上書きできます。

1. EXE と同じフォルダの `data/custom.css` を編集 (初回起動時に説明コメント付きで自動生成されます)
2. メニュー **「設定 > ユーザーCSSを再読み込み」** で再起動せずに反映

```css
/* 例: 全体をセピア調にする */
:root { --bg: #f4ecd8; --panel: #fbf5e6; --ink: #4a3f2a; }

/* 例: レス本文の行間を広げる */
.response-body { line-height: 1.8; }
```

配色は CSS 変数で一括変更でき、レス 1 件の内部構造 (`.rh` 直下に並ぶヘッダー項目・ID 列など) までクラス指定で個別カスタマイズできます。
また、汎用掲示板ブラウザ **SIKI と互換のセレクタ・テーマ変数・ファイル構成** (`data/theme/`) に対応しており、
SIKI のカスタム CSS レシピの多くをそのまま流用できます。
詳細は **[docs/CSS_CUSTOMIZE.md](docs/CSS_CUSTOMIZE.md)** を参照してください
(変数一覧・全 UI 要素のクラスリファレンス・SIKI 互換対応表・レシピ集を収録)。

## 設定ファイル（Portable 形式）

全ファイルは EXE と同じフォルダの `data/` に自動生成されます。フォルダごとコピーすれば環境を丸ごと移行できます。
AppData (`%APPDATA%` / `%LOCALAPPDATA%` / `%TEMP%`) にはファイルを作らず、レジストリにも書き込みません。

> **v0.0.113 以前から使っている場合:** 以前は画面部分 (WebView2) のキャッシュが
> `%LOCALAPPDATA%\io.livefake.browser` に作られていました (設定・履歴は含まれません)。
> v0.0.114 以降は使われないので、不要であればフォルダごと削除してください。
> VOICEVOX 読み上げの一時ファイル `%TEMP%\livefake_voicevox.wav` も同様に削除してかまいません。

| `overlay-appearance.json` / `overlay-layouts.json` | OBS 表示の見た目 / レイアウト |
| `eventlog/` | ログファイル (デフォルト7日保持) |
| `webview/` | 画面部分 (WebView2) のキャッシュ等。上限は設定で変更可 (既定 100MB)。いつ削除してもよく、移行時のコピーも不要 |
| `tmp/` | 一時ファイル (終了時・次回起動時に削除) |
