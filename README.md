# LiveFake

**実況向け掲示板ブラウザ＋Twitchビュワー** — Tauri v2 (Rust) + React デスクトップアプリ

5ch.io / したらば / JPNKN の3サイトに対応した Portable 形式の実況専用ブラウザです。
ZIP を展開するだけでインストール不要で使えます。

## 最新の更新 (v0.0.119)

**配信向けの大きな更新です。** Twitch・YouTube のチャットを、掲示板と一緒に見る・読み上げる・OBS に出すことができるようになりました。

### 新機能

- **Twitch のチャット**: アドレスバーに `twitch.tv/チャンネル名` を入れると Twitch タブが開き、チャットがレスと同じ形で流れます (ログイン不要・読み取り専用)。
  スタンプ・バッジの画像、サブスク・ビッツ・レイドなどのイベント (種類ごとに表示・読み上げを選べる)、視聴者の「教育・忘却」コマンド (既定オフ) に対応。
  配信者本人が Twitch にログインすると (任意)、入力の無いチャンネルポイント報酬・フォローも表示できます
- **YouTube のライブ配信のチャット**: ライブ配信の URL を入れると YouTube タブが開きます。YouTube Data API の API キー (各自で無料で作成。設定 > YouTube) が必要です。
  スーパーチャット・メンバー加入などのイベント、削除されたコメントの反映、チャンネル独自の絵文字に対応
- **ビュワー** (板タブの左端): Twitch・YouTube のチャットと、配信ホワイトリストに入れた ID のレスを1本にまとめて表示します。
  リンクカード・画像のサムネイル、ホワイトリスト以外の新着を見る「スレの最新レス」欄、単語による ID の自動追加
- **OBS 表示**: ビュワーと同じ内容を OBS の「ブラウザ」ソース (`http://127.0.0.1:11290/overlay.html`) で表示します (既定オフ)。
  見た目を「レイアウト」として複数保存でき、追加 CSS も書けます。画像・リンクカードは配信に出しません
- **設定 > 接続**: Twitch のチャンネル・YouTube の配信・スレをまとめて追加。タブごとに読み上げをオンオフ
- 掲示板に書かれたスタンプ名を画像で表示 (`BIG`+名前で巨大表示)
- レスの右クリックに「このレスから新着として流す」、掲示板の読み上げ方に「ホワイトリスト以外はレス番のみ」
- 起動時の更新確認 (1日1回)・書き込み履歴の保存・タブの左端のサイトの色の線・字幕ウィンドウの大きさの記憶・字幕の背景の透明度 0

### 変更

- 旧「OBS連携」(専用ウィンドウをキャプチャする方式) を廃止しました。**OBS のウィンドウキャプチャを「ブラウザ」ソースに入れ替えてください**
  (設定 > ビュワー > OBS 表示 で「OBS 表示を使う」をオン)
- **custom.css などの利用者の CSS が、指定の強さに関係なく常に標準の見た目より優先**されるようになりました。これまで効かなかった指定が効くようになることがあります
- 画面の見やすさ (文字と背景の色の差など)・設定画面・メニューを整理しました

### 修正・セキュリティ

- ウィンドウが低いと設定画面がはみ出す問題、「スレURLをコピー」が板の URL をコピーする問題を修正
- LiveFake を更新したあと、OBS 表示のページを自動で読み込み直すように (古いページが残らない)
- 家庭内・自分の PC のアドレスの画像は、サムネイル・カードとして読み込まないように
- 依存ライブラリの既知の脆弱性を修正 (rustls・rustls-webpki・quick-xml)

詳しい内容は [CHANGELOG](https://github.com/kaedekiku/LiveFakeTauri2/blob/main/CHANGELOG.md)、使い方は [説明書](https://github.com/kaedekiku/LiveFakeTauri2/blob/main/docs/USER_MANUAL.md) (11 章) を参照してください。

## 主な機能

### 掲示板の閲覧

- **3サイト対応**: 5ch.io (Shift_JIS) / したらば (EUC-JP、ID 付き) / JPNKN (Shift_JIS) — エンコーディング自動判別
- **板一覧**: カテゴリーツリー表示・検索フィルタ・お気に入り板（ドラッグで並べ替え）
- **外部板登録**: したらば・JPNKN の板を URL で追加
- **スレッド一覧**: 全列ソート・検索・既読/未読管理・勢いバー・dat 落ちスレのグレーアウト表示・キャッシュ閲覧・カスタムタイトル
- **マルチタブ**: 板タブ + スレタブの2段構成。ドラッグ並べ替え・中クリックで閉じる・タブ上限設定 (既定20、変更可)
- **自動更新**: 1秒刻み (10〜300秒) で新着レスを自動取得。バックグラウンドタブも差分取得
- **セッション復元**: 前回のタブ・ウィンドウサイズ・レイアウトを次回起動時に復元

### レス表示

- アンカーポップアップ (`>>N`, `>>N-M`, `>>N,M` 対応・多段ネスト)
- ID 色分け・書き込み回数表示 (2回以上=青、5回以上=赤)・同一 ID レス一覧ポップアップ
- 被参照数表示 (▼N) とポップアップ
- 自分の投稿 [自分] / 自分宛レス [自分宛] の自動検出
- 新着マーカー「ここから新着」 / New! ラベル
- ASCII アート自動検出・等幅フォント切替 (右クリックで手動切替も可)
- 画像 URL 自動サムネイル (サイズ上限でクリックするまで非表示にする設定あり)・ホバープレビュー (ズーム対応)・別ウィンドウ表示・保存
- **リンクカード**: 本文中の URL を OGP 情報 (タイトル・説明・画像) 付きのカードで表示。X (Twitter) のポスト・YouTube 動画に対応（既定 OFF、通信先ドメイン制限あり）
- リンクフィルタ (画像 / 動画 / 外部リンクを含むレスのみ表示)
- 栞 (最後に読んだ位置) とスクロール位置の自動保存

### 書き込み

- 下部の書き込みウィンドウ（返信専用）: 名前 (履歴付き) / メール / sage、送信ショートカット (Shift+Enter / Ctrl+Enter 選択式)、投稿後の見た目を確認できるプレビュータブ
- **書き込みの浮遊ウィンドウ**: スレッドタイトルバーの「書き込み」から開く独立したウィンドウ。返信・**新スレ立て** (5ch / したらば / JPNKN) の両方に対応し、投稿成功で自動的に閉じる
- ダブルクリックでレス引用、名前付き引用（浮遊ウィンドウを開いているときはそちらに反映）
- 書き込み履歴 (最大 50 件。返信・スレ立てを記録し、再起動しても残る)

### 実況特化機能

| 機能 | 説明 |
|------|------|
| **新着レスペイン** | 新着レスを1件ずつ順番に表示するサブパネル。長文はゆっくり自動スクロール (時間・速度を調整可)。クリックで該当レスへジャンプ。 |
| **字幕ウィンドウ** | 半透明オーバーレイの別ウィンドウに新着レスを最前面表示。透明度・フォント・スクロールバー・一時停止 (▶で再開) に対応。新着ペインとの表示同期を選択可。 |
| **音声読み上げ** | SAPI / 棒読みちゃん / VOICEVOX の3エンジン対応。新着レス自動読み上げ・読み上げ辞書 (単語置換)・IP 配信 URL 用の読み上げ許可リスト・読み上げない辞書 (名前/本文/ID) 付き。 |
| **Twitch チャット** | アドレスバーに `twitch.tv/チャンネル名` を入れると、そのチャンネルのチャットをスレと同じ形で表示。新着レスペイン・字幕・読み上げ (「名前さん」+本文)・NG・ハイライトにそのまま流れる。ログイン不要の読み取り専用 (書き込みはできない)。 |
| **YouTube のライブ配信のチャット** | アドレスバーにライブ配信の URL を入れると、その配信のチャットをスレと同じ形で表示。新着レスペイン・字幕・読み上げ・NG・ハイライト・ビュワー・OBS 表示に流れる。スーパーチャット・メンバー加入などのイベントは種類ごとに表示・読み上げを選べる。削除された発言は消える。YouTube Data API の API キー (各自で作成) が必要。読み取り専用。 |
| **ビュワー** | 板タブの左端。Twitch・YouTube のチャットと、配信ホワイトリストの ID のレスをまとめて表示し、OBS のブラウザソース (`http://127.0.0.1:11290/overlay.html`) にも出せる。ホワイトリストの直接入力・単語による自動追加、ホワイトリスト以外はレス番だけ読む読み上げ方式、下部に最新レス欄。 |
| **接続・タブごとの読み上げ** | 設定 > 接続 で Twitch チャンネル・YouTube のライブ配信・スレをまとめて追加。読み上げはタブ (スレ・チャンネル) ごとにオンオフできる。 |

### フィルター・ハイライト

- **NG フィルター**: ワード / ID / 名前 / メール / スレタイ / 画像NG (一致したレスの画像だけ非表示)。ワードNGは正規表現対応。
  名前か本文に**見えない文字** (幅ゼロの空白・文字の向きを変える制御文字など) を含むレスも NG にできます (既定オフ)。
- **NG モード**: 項目ごとに選択可能。透明あぼ～ん (非表示) / 通常あぼ～ん (名前・メール・投稿日・本文を「あぼ～ん」表示、本文はホバーで理由表示)
- **NG スコープ**: 全体 / この板 / このスレ
- **ハイライト**: 15色パレットでワード・名前・ID を色分け (ID ハイライトは当日限り有効)。字幕ウィンドウにも同期。
- 右クリックメニューから NG 追加・ハイライト設定を即時適用

### 配信ソフトとの連携 (既定オフ)

| 機能 | 説明 |
|------|------|
| **OBS 表示** | ビュワーと同じ内容 (Twitch・YouTube のチャットと配信ホワイトリストの ID のレス) を、OBS の「ブラウザ」ソースで表示します (`http://127.0.0.1:11290/overlay.html`、このPCの中からだけ見られます)。見た目に名前を付けた「レイアウト」を複数保存でき、`?layout=名前` でソースごとに使い分けられます。レイアウトごとに追加 CSS も書けます |

詳細は [docs/USER_MANUAL.md](docs/USER_MANUAL.md) 11.7 節を参照してください。以前の「OBS連携」(専用ウィンドウをキャプチャする方式) は廃止しました。

### 設定・カスタマイズ

- ライト / ダークモード
- フォント・各ペイン文字サイズ・レス間隔・レスヘッダの表示項目などをGUIで細かく調整
- 設定画面は節タブ・検索窓・保存ボタン・プリセット・自動バックアップ・リセットに対応（詳細は [docs/USER_MANUAL.md](docs/USER_MANUAL.md) 14章）
- **ユーザー CSS**: `data/custom.css` / `data/theme/` で UI の見た目を自由にカスタマイズ（SIKI 互換） → [CSS カスタマイズガイド](docs/CSS_CUSTOMIZE.md)
- 画像 URL 置換ルール (`ImageViewURLReplace.txt`) でサムネイル変換をカスタマイズ
- 検索窓・スレ立てなどの入力欄は過去入力を候補表示 (履歴は設定からまとめて消去可)

> **注意:** プロキシ設定 UI は存在しますが、**現バージョンでは正常に動作しません** (設定値は保存されますが通信に反映されない)。実装対応予定の項目を参照してください。

## CSS で見た目を変える

LiveFake は UI 全体をユーザーの CSS で上書きできます。

1. EXE と同じフォルダの `data/custom.css` を編集 (初回起動時に説明コメント付きで自動生成されます)
2. メニュー **「設定 > ユーザーCSSを再読み込み」** で再起動せずに反映

```css
/* 例: 全体をセピア調にする */
:root { --bg: #f4ecd8; --panel: #fbf5e6; --ink: #4a3f2a; }

/* 例: レス本文の行間を広げる */
.response-body { line-height: 1.8; }
```

配色は CSS 変数で一括変更でき、レス 1 件の内部構造 (`.rh` 直下に並ぶヘッダー項目・ID 列など) までクラス指定で個別カスタマイズできます。
また、汎用掲示板ブラウザ **SIKI と互換のセレクタ・テーマ変数・ファイル構成** (`data/theme/`) に対応しており、
SIKI のカスタム CSS レシピの多くをそのまま流用できます。
詳細は **[docs/CSS_CUSTOMIZE.md](docs/CSS_CUSTOMIZE.md)** を参照してください
(変数一覧・全 UI 要素のクラスリファレンス・SIKI 互換対応表・レシピ集を収録)。

## 設定ファイル（Portable 形式）

全ファイルは EXE と同じフォルダの `data/` に自動生成されます。フォルダごとコピーすれば環境を丸ごと移行できます。
AppData (`%APPDATA%` / `%LOCALAPPDATA%` / `%TEMP%`) にはファイルを作らず、レジストリにも書き込みません。

> **v0.0.113 以前から使っている場合:** 以前は画面部分 (WebView2) のキャッシュが
> `%LOCALAPPDATA%\io.livefake.browser` に作られていました (設定・履歴は含まれません)。
> v0.0.114 以降は使われないので、不要であればフォルダごと削除してください。
> VOICEVOX 読み上げの一時ファイル `%TEMP%\livefake_voicevox.wav` も同様に削除してかまいません。

| ファイル / フォルダ | 内容 |
|---------|------|
| `settings.ini` | アプリ全般設定 (表示・自動更新・読み上げ・書き込み・プロキシ) |
| `custom.css` / `theme/` | ユーザーカスタム CSS (SIKI 互換構成) |
| `layout_prefs.json` | 値の設定（文字サイズ・ヘッダ表示項目・スクロール設定など） |
| `presets/` / `settings-backup/` | 設定のプリセット / 自動バックアップ |
| `ng-settings.json` | NG フィルター |
| `text-highlights.json` / `id-highlights.json` | ハイライト設定 (ID は当日分) |
| `tts-dict.json` / `tts-ip-allow.json` / `tts-mute-dict.json` | 読み上げ辞書 / 許可リスト / 読み上げない辞書 |
| `ogp_domain_filters.json` | リンクカードの通信先ドメイン許可/ブロックリスト |
| `board-catalog.json` / `external-boards.json` | お気に入り板 / 外部板 |
| `session_tabs.json` / `session_board_tabs.json` | セッション (開いているタブ) |
| `bookmarks.json` / `scroll-positions.json` / `read_status.json` | 栞・スクロール位置・既読 |
| `thread-history.json` | スレ履歴 (既読数・訪問時刻・カスタムタイトル) |
| `input-history.json` / `name-history.json` / `search-history.json` | 入力欄・名前・検索の履歴 |
| `cache.db` | スレッドレスキャッシュ / リンクカードキャッシュ (SQLite) — dat 落ちスレの閲覧に利用 |
| `ImageViewURLReplace.txt` | 画像 URL 置換ルール (TSV) |
| `eventlog/` | ログファイル (デフォルト7日保持) |
| `webview/` | 画面部分 (WebView2) のキャッシュ等。上限は設定で変更可 (既定 100MB)。いつ削除してもよく、移行時のコピーも不要 |
| `tmp/` | 一時ファイル (終了時・次回起動時に削除) |

## 謝辞

LiveFakeTauri2 は [kiyohken2000](https://github.com/kiyohken2000) 氏による [Ember (5ch-browser-template)](https://github.com/kiyohken2000/5ch-browser-template) をベースにしています（MIT License）。

Ember から継承している基盤:
- Tauri + Rust + React/TypeScript のデスクトップアプリ構成
- BBS データパーサ（dat / subject.txt / bbsmenu）
- JSON 永続化 / SQLite キャッシュ機構
