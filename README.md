# LiveFake

**実況向け日本語掲示板ブラウザ** — Tauri v2 (Rust) + React デスクトップアプリ

5ch.io / したらば / JPNKN の3サイトに対応した Portable 形式の実況専用ブラウザです。
ZIP を展開するだけでインストール不要で使えます。

## 主な機能

### 掲示板の閲覧

- **3サイト対応**: 5ch.io (Shift_JIS) / したらば (EUC-JP、ID 付き) / JPNKN (Shift_JIS) — エンコーディング自動判別
- **板一覧**: カテゴリーツリー表示・検索フィルタ・お気に入り板（ドラッグで並べ替え）
- **外部板登録**: したらば・JPNKN の板を URL で追加
- **スレッド一覧**: 全列ソート・検索・既読/未読管理・勢いバー・dat 落ちスレのグレーアウト表示・キャッシュ閲覧・カスタムタイトル
- **マルチタブ**: 板タブ + スレタブの2段構成。ドラッグ並べ替え・中クリックで閉じる・タブ上限設定 (既定20、変更可)
- **自動更新**: 1秒刻み (10〜300秒) で新着レスを自動取得。バックグラウンドタブも差分取得
- **セッション復元**: 前回のタブ・ウィンドウサイズ・レイアウトを次回起動時に復元

### レス表示

- アンカーポップアップ (`>>N`, `>>N-M`, `>>N,M` 対応・多段ネスト)
- ID 色分け・書き込み回数表示 (2回以上=青、5回以上=赤)・同一 ID レス一覧ポップアップ
- 被参照数表示 (▼N) とポップアップ
- 自分の投稿 [自分] / 自分宛レス [自分宛] の自動検出
- 新着マーカー「ここから新着」 / New! ラベル
- ASCII アート自動検出・等幅フォント切替 (右クリックで手動切替も可)
- 画像 URL 自動サムネイル (サイズ上限でクリックするまで非表示にする設定あり)・ホバープレビュー (ズーム対応)・別ウィンドウ表示・保存
- **リンクカード**: 本文中の URL を OGP 情報 (タイトル・説明・画像) 付きのカードで表示。X (Twitter) のポスト・YouTube 動画に対応（既定 OFF、通信先ドメイン制限あり）
- リンクフィルタ (画像 / 動画 / 外部リンクを含むレスのみ表示)
- 栞 (最後に読んだ位置) とスクロール位置の自動保存

### 書き込み

- 下部の書き込みウィンドウ（返信専用）: 名前 (履歴付き) / メール / sage、送信ショートカット (Shift+Enter / Ctrl+Enter 選択式)、投稿後の見た目を確認できるプレビュータブ
- **書き込みの浮遊ウィンドウ**: スレッドタイトルバーの「書き込み」から開く独立したウィンドウ。返信・**新スレ立て** (5ch / したらば / JPNKN) の両方に対応し、投稿成功で自動的に閉じる
- ダブルクリックでレス引用、名前付き引用（浮遊ウィンドウを開いているときはそちらに反映）
- 書き込み履歴 (最大 50 件)

### 実況特化機能

| 機能 | 説明 |
|------|------|
| **新着レスペイン** | 新着レスを1件ずつ順番に表示するサブパネル。長文はゆっくり自動スクロール (時間・速度を調整可)。クリックで該当レスへジャンプ。 |
| **字幕ウィンドウ** | 半透明オーバーレイの別ウィンドウに新着レスを最前面表示。透明度・フォント・スクロールバー・一時停止 (▶で再開) に対応。新着ペインとの表示同期を選択可。 |
| **音声読み上げ** | SAPI / 棒読みちゃん / VOICEVOX の3エンジン対応。新着レス自動読み上げ・読み上げ辞書 (単語置換)・IP 配信 URL 用の読み上げ許可リスト・読み上げない辞書 (名前/本文/ID) 付き。 |

### フィルター・ハイライト

- **NG フィルター**: ワード / ID / 名前 / メール / スレタイ / 画像NG (一致したレスの画像だけ非表示)。ワードNGは正規表現対応。
- **NG モード**: 項目ごとに選択可能。透明あぼ～ん (非表示) / 通常あぼ～ん (名前・メール・投稿日・本文を「あぼ～ん」表示、本文はホバーで理由表示)
- **NG スコープ**: 全体 / この板 / このスレ
- **ハイライト**: 15色パレットでワード・名前・ID を色分け (ID ハイライトは当日限り有効)。字幕ウィンドウにも同期。
- 右クリックメニューから NG 追加・ハイライト設定を即時適用

### 設定・カスタマイズ

- ライト / ダークモード
- フォント・各ペイン文字サイズ・レス間隔・レスヘッダの表示項目などをGUIで細かく調整
- 設定画面は節タブ・検索窓・保存ボタン・プリセット・自動バックアップ・リセットに対応（詳細は [docs/USER_MANUAL.md](docs/USER_MANUAL.md) 14章）
- **ユーザー CSS**: `data/custom.css` / `data/theme/` で UI の見た目を自由にカスタマイズ（SIKI 互換） → [CSS カスタマイズガイド](docs/CSS_CUSTOMIZE.md)
- 画像 URL 置換ルール (`ImageViewURLReplace.txt`) でサムネイル変換をカスタマイズ
- 検索窓・スレ立てなどの入力欄は過去入力を候補表示 (履歴は設定からまとめて消去可)

> **注意:** プロキシ設定 UI は存在しますが、**現バージョンでは正常に動作しません** (設定値は保存されますが通信に反映されない)。実装対応予定の項目を参照してください。

## CSS で見た目を変える

LiveFake は UI 全体をユーザーの CSS で上書きできます。

1. EXE と同じフォルダの `data/custom.css` を編集 (初回起動時に説明コメント付きで自動生成されます)
2. メニュー **「設定 > ユーザーCSSを再読み込み」** で再起動せずに反映

```css
/* 例: 全体をセピア調にする */
:root { --bg: #f4ecd8; --panel: #fbf5e6; --ink: #4a3f2a; }

/* 例: レス本文の行間を広げる */
.response-body { line-height: 1.8; }
```

配色は CSS 変数で一括変更でき、レス 1 件の内部構造 (`.rh` 直下に並ぶヘッダー項目・ID 列など) までクラス指定で個別カスタマイズできます。
また、汎用掲示板ブラウザ **SIKI と互換のセレクタ・テーマ変数・ファイル構成** (`data/theme/`) に対応しており、
SIKI のカスタム CSS レシピの多くをそのまま流用できます。
詳細は **[docs/CSS_CUSTOMIZE.md](docs/CSS_CUSTOMIZE.md)** を参照してください
(変数一覧・全 UI 要素のクラスリファレンス・SIKI 互換対応表・レシピ集を収録)。

## 設定ファイル（Portable 形式）

全ファイルは EXE と同じフォルダの `data/` に自動生成されます。フォルダごとコピーすれば環境を丸ごと移行できます。

| ファイル / フォルダ | 内容 |
|---------|------|
| `settings.ini` | アプリ全般設定 (表示・自動更新・読み上げ・書き込み・プロキシ) |
| `custom.css` / `theme/` | ユーザーカスタム CSS (SIKI 互換構成) |
| `layout_prefs.json` | 値の設定（文字サイズ・ヘッダ表示項目・スクロール設定など） |
| `presets/` / `settings-backup/` | 設定のプリセット / 自動バックアップ |
| `ng-settings.json` | NG フィルター |
| `text-highlights.json` / `id-highlights.json` | ハイライト設定 (ID は当日分) |
| `tts-dict.json` / `tts-ip-allow.json` / `tts-mute-dict.json` | 読み上げ辞書 / 許可リスト / 読み上げない辞書 |
| `ogp_domain_filters.json` | リンクカードの通信先ドメイン許可/ブロックリスト |
| `board-catalog.json` / `external-boards.json` | お気に入り板 / 外部板 |
| `session_tabs.json` / `session_board_tabs.json` | セッション (開いているタブ) |
| `bookmarks.json` / `scroll-positions.json` / `read_status.json` | 栞・スクロール位置・既読 |
| `thread-history.json` | スレ履歴 (既読数・訪問時刻・カスタムタイトル) |
| `input-history.json` / `name-history.json` / `search-history.json` | 入力欄・名前・検索の履歴 |
| `cache.db` | スレッドレスキャッシュ / リンクカードキャッシュ (SQLite) — dat 落ちスレの閲覧に利用 |
| `ImageViewURLReplace.txt` | 画像 URL 置換ルール (TSV) |
| `eventlog/` | ログファイル (デフォルト7日保持) |
